Android App UI (Jetpack Compose + Material 3)

This project demonstrates a complete app layout built with Scaffold in Jetpack Compose.
It includes:

Top App Bar with navigation drawer access

Navigation Drawer with sections for Home, Categories, Profile, Favorites, Settings, and About

Bottom Navigation Bar with four tabs (Home, Favorite, Settings, Profile)

Central Content using LazyColumn with Material 3 styled cards

Floating Action Button (FAB) for primary actions

The design follows Material 3 guidelines, is fully responsive, and provides smooth navigation with preserved screen state.
